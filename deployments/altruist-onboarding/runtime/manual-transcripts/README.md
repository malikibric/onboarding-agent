# Manual Transcripts

Evidence from **interactive** `/onboard` runs in Claude Code goes here — one file per session, e.g. `2026-07-27-first-onboard-run.md`.

Keep these separate from `runtime/transcripts/`, which holds outputs from the **automated** evaluator (`runtime/run_eval.py`) and is graded by `runtime/grader.py`. Manual transcripts are not graded automatically; a human reads them. Mixing the two makes it unclear which claims are machine-verified and which are human-observed.

See `docs/manual-onboard-test.md` for the test script and what to record.
