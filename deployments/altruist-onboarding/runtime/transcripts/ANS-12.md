**Verdict:** PASS

## Question

What does Hazel say about security?

## Answer

Hazel's public materials include security messaging: they state that client data is not used to train foundation models, that data is encrypted, that enterprise-grade security is central to the product's design, and that zero-data-retention arrangements with AI providers are used where applicable.

Important caveat: this is Altruist's published marketing language, not a verified technical control, and it shouldn't be repeated to a client or prospect as an assurance. For anything more specific — or if you need to represent security posture to a client — that's a question for Security or Compliance.
